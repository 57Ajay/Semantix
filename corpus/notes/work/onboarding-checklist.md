# New engineer onboarding checklist

## Day 1

- [ ] Laptop from IT, enable disk encryption
- [ ] Single sign-on account, set up two-factor authentication with a hardware key
- [ ] VPN profile installed and tested from home
- [ ] Join the team chat channels: #eng, #deploys, #incidents
- [ ] Read the engineering handbook, especially "how we review code"

## Week 1

- [ ] Access to the main repositories and the staging environment
- [ ] Run the whole test suite locally
- [ ] Pair with a buddy on one small bug fix and ship it to production
- [ ] Shadow one on-call shift

## Month 1

- [ ] Own one small feature from design to release
- [ ] Present a short demo at the Friday meeting
