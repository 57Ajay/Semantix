# Home network notes

- Router admin page: http://192.168.1.1, admin account in the password manager.
- Main network for our own devices, 5 GHz and 2.4 GHz on the same name.
- Guest network is separate so visitors cannot see the printer or the NAS. The guest
  password is printed on the card on the fridge; change it every few months.
- Firmware updated 3 March 2024. Check again every quarter.
- The NAS gets a fixed address, 192.168.1.20, set as a reservation on the router.
- If the internet drops: restart the modem first, wait two minutes, then the router.
